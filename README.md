# 💎 NexusBank Pro - Modern ATM System

A modern **ATM simulation app** built with **Python Tkinter**.  
It supports **account creation, authentication, deposits, withdrawals, transfers, and transaction history** with a polished UI.

---

## ✨ Features
- 🧑‍💼 User Authentication (PIN protected)
- 💳 Create new accounts with initial deposit
- 💰 Balance check
- 💸 Deposit / Withdraw money
- 🔀 Transfer funds between accounts
- 📊 Transaction history with date filters
- 🎨 Modern UI with custom styles

---

## 📂 Tech Stack
- **Python** (Tkinter GUI)
- **SQLite3** (Database)
- **tkcalendar** (Date filters)
- **matplotlib** (Transaction visualization)

---

Install dependencies:

pip install -r requirements.txt


Run the app:

python atm.py


## 📖 Usage

Launch the app with python atm.py.

Create a new account (you’ll get an account ID).

Sign in with account ID and PIN.

Perform transactions and track history.

🛠 Database

The app uses SQLite (atm.db file).

Tables:

users → stores user details & balances

transactions → stores all user transactions
